# 内核防线

> 最后更新：2026-10-02

**内核防线**是一个"双层总线"塔防小游戏：入侵进程（病毒 / 蠕虫 / 木马 / 勒索软件，每 5 波还有根套件 Boss）沿电路总线冲向中央的 CPU 核心，你把防御程序装到固定焊盘上拦截它们。

它的独特之处不在"塔"，而在**机房本身也是资源**：

- 每个防御程序都要吃一份 **功耗**，总功耗不能超过 **供电容量**；
- 程序开火会 **发热**，机房靠 **散热** 降温；温度过高时全部程序 **降频**（射速下降），再高核心会直接 **过热掉血**；
- 所以"多建塔"不是免费的，你需要用算力不断 **扩容**（同时提升供电容量与散热）。

> 一句话上手：**选防御程序 → 点空焊盘部署 → 点击敌人可用 SIGKILL 秒杀 → 撑过一波波入侵**。

## 能做什么

- 4 种防御程序：扫描器（速射单体）、防火墙（溅射+减速）、杀毒引擎（远程高伤无视护甲）、蜜罐（持续产算力）。
- 每座塔可升级到 3 级；升级同时增加功耗，要留意供电。
- 2 个手动技能：**SIGKILL**（点杀任意敌人，冷却 6 秒）、**超频**（全塔短时加速，发热翻倍）。
- 5 种敌人 + 每 5 波一只 **根套件 Boss**（会持续召唤蠕虫）。
- 无尽波次，难度随波次上升；纪录（最高波次 / 最多击杀 / 最高分）持久化到本机。

## 界面速览

| 区域       | 说明                                                         |
| ---------- | ------------------------------------------------------------ |
| 顶部状态条 | 波次、核心完整度、算力、功耗/容量、温度（附降频 / 过热提示） |
| 建造栏     | 4 个防御程序按钮，显示造价 ⌘ 与功耗 ⚡；数字键 1–4 快捷选择  |
| 操作栏     | 立即迎战（提前开战有算力奖励）、超频、扩容、暂停             |
| 选中面板   | 选中已建塔后出现：升级 / 拆除                                |
| 战场       | 两条总线从左侧入场，在右侧合流冲向 CPU 核心                  |

## 常见操作

### 部署与升级

1. 点建造栏里的防御程序（或按数字键 1–4）。
2. 战场上的空焊盘会高亮：绿色 = 可部署，红色 = 算力不足或供电不够。
3. 再次点已建的塔可以选中它，顶部会出现 **升级 / 拆除**。

### SIGKILL 与超频

- **SIGKILL**：鼠标移到敌人上会变成十字准星，单击即可造成 95 点伤害，冷却 6 秒。
- **超频**：按 **O** 或点按钮，4 秒内全塔射速 +60%，但发热大幅上升、整体温度会飙高。冷却 20 秒。

### 温度与供电

- 温度超过 **92°C** 开始降频，超过 **126°C** 核心开始过热掉血。
- 点 **扩容** 同时提升供电容量（能装更多/更强的塔）与散热（更快降温）。
- 漏过去的敌人会扣核心完整度；点 **检修** 花算力恢复 12 点（每次涨价，直到满值）。

### 暂停

- **P** 或 **Esc** 暂停 / 继续。
